# Movie Correlation Analysis

Completed as a guided learning exercise following Alex the Analyst's tutorial series — built to practice pandas data cleaning and correlation analysis with seaborn/matplotlib. Credit to Alex the Analyst for the original tutorial and dataset.

This project analyzes movie data from 1990–2020 to explore which factors are most correlated with gross earnings.

## Focus
1. Examined the correlation between various factors — including the impact of budget on gross earnings.
2. Evaluated every field in the dataset for its correlation with gross earnings.

## Findings
1. Correlation analysis of numeric factors against gross earnings:
   - Budget showed the strongest correlation with gross earnings.
   - Number of votes was the next strongest correlated factor.
   - All other numeric factors showed noticeably weaker correlation.
2. Several non-numeric fields (production company, country, genre, and movie name) were converted to numeric values to test their correlation with gross earnings as well.

## Tools Used
Python (pandas, seaborn, matplotlib) in a Jupyter Notebook.
